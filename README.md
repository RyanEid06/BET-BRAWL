# BET & BRAWL

A party game for 3–9 players with 14 games, tournaments and spectator betting.

- [Download Android V2.1 APK](https://github.com/RyanEid06/BET-BRAWL/releases/download/v2.1.0/BET-BRAWL-V2.1-2.1.0-code4.apk)
- [Play the latest web version](https://bet-brawl.northstack-labs.workers.dev)

Android V2.1 is **2.1.0**, versionCode **4**, for Android 7.0 or newer. Install it directly over the production V2 app to retain saved data and settings. Android players connect to the same Wi-Fi; web players can join from different networks with internet access. At least three players must join before starting.

V2.1 improves Quick Draw, Millisecond Stop, Rapid Red Light/Green Light and Blind Pinpoint, and adds short fighter instructions for every game.

Source branches: `main` for Android, `v2-web` for the live website, and `v1` for historical source.

Blind Pinpoint uses public-domain Natural Earth map geometry.

## Goal and boundaries

Deliver eight new games alongside V1's six, first online (phone and PC), then Android/LAN. Retain 3–9 players, spectator betting, qualifier scoring, championship and bankroll rules. New rounds generally15–30s excluding instructions/betting. No new modes, matchmaking, accounts, dependencies or redesign. Candidate branches only: merging, deployment and publication are separate release actions.

Keep React, TypeScript authoritative rules, Cloudflare Durable Objects, Node reference host and Kotlin LAN host. Use focused game modules/components and existing dependencies. Shared fixtures contain content/actions/times/views/results; identical PRNG implementations unnecessary.
